Full walkthrough

  1. Fill in the form on the left. The preview and the code on the right update as you type.
  2. If you're publishing an actual file: drop the PDF into assets/publications/ (create that folder if it doesn't exist yet), and use its path as the Link, e.g. assets/publications/q3-briefing.pdf.
  3. Click Copy code.
  4. Open js/main.js in VS Code, find the PUBLICATIONS list near the top, and paste your new entry right after the line that says // ADD NEW PUBLICATIONS BELOW THIS LINE.
  5. Save the file, and re-upload the site (or push to whatever host you're using - Netlify, Vercel, etc). The new item will appear in the Insights section automatically, already wired into the filter tabs.
